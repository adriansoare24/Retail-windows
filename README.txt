RETAIL WINDOWS V2
==================
Aplicatie locala pentru Windows 10.

Module V2:
- Dashboard
- POS / vanzare
- discount
- plata numerar/card/transfer
- produse si coduri de bare
- stoc
- receptie marfa
- furnizori
- clienti
- inventar
- retururi
- rapoarte
- utilizatori
- backup/restaurare
- setari

Casa de marcat NU este conectata.

Pentru EXE pe Windows 10:
1. Instaleaza Python 3.11+ pe PC.
2. Deschide folderul.
3. Ruleaza build_exe.bat.
4. Executabilul va fi in dist\RetailWindowsV2.exe.

Cont initial: admin / admin.
Schimba parola inainte de utilizarea reala.
